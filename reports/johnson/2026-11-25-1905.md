注意力机制与 Transformer 的内部运作，第 8/8 天（主题弧收尾）：鹭洲长歌会上的两个女孩。

**核心机制**：归纳头实现 […A][B]…[A]→[B]；由较早层的前一 token 头（借位置信息注意 i-1，把前一 token 写入残差流）与较后层的归纳头（查询匹配“前一 token 为 A”的键，OV 把 B 写回、提升 B 的 logit）经 K-组合构成，故至少两层（Elhage et al., **2021**）；单层纯注意力≈二元统计+跳跃三元组。与内容无关、不改权重，是上下文学习的一种具体机制。上下文学习分数=第500 token 损失−第50 token 损失（Olsson et al., **2022**）。训练早期出现相变：归纳头形成、ICL 分数陡降、损失曲线出现小鼓包，单层模型无此现象；小型纯注意力模型有较直接的因果（消融）证据，大模型主要为相关性证据。

**隐喻映射**：唱字=token；抢先接下一个字=下一 token 预测；旧歌本=权重中的训练统计；“阿”接“阿妈”=只靠语料统计；连夜背新歌=微调（错误方向）；第50字 vs 第500字竹签=ICL 分数；竹牌长案=残差流；牌角编号=位置信息；只看一眼=单个注意力头一次读取；阿棹独自=单层纯注意力；阿篙在牌边写“前一张是某”=前一 token 头加写残差流；阿棹找“前一张是阿”=归纳头 K-组合；怪音唱两遍=重复随机 token 实验；座次对调全乱=前层写后层读；一个多月不见起色后陡升=相变与鼓包；不背新歌却越唱越准=推理时权重固定

**故事片段**：鹭洲是江心十几座沙洲连成的一片。每年秋汛退去，洲上开长歌会，规矩有些古怪：歌手即兴编一首长歌，一唱就是大半夜，歌里的人名、船名、地名大半是当场现编的——这一首是"阿铎撑着青篷船去了渡溪"，下一首也许就是"缪婆婆的黑狗叫汪七"。歌手身边站一个接腔的孩子，歌手每唱一个字，孩子要抢先半拍把下一个字唱出来。唱对了叫"合腔"，唱错了叫"落腔"。
