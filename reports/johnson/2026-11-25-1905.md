## 分题探查

### 1. 故事：《鹭洲长歌会上的两个女孩》

鹭洲是江心十几座沙洲连成的一片。每年秋汛退去，洲上开长歌会，规矩有些古怪：歌手即兴编一首长歌，一唱就是大半夜，歌里的人名、船名、地名大半是当场现编的——这一首是"阿铎撑着青篷船去了渡溪"，下一首也许就是"缪婆婆的黑狗叫汪七"。歌手身边站一个接腔的孩子，歌手每唱一个字，孩子要抢先半拍把下一个字唱出来。唱对了叫"合腔"，唱错了叫"落腔"。

台下的鼓师葛婆专管记分。她记分的法子和别人不同：一首歌唱完，她不看合腔的总数，只拿两根竹签比——第五十个字前后合腔几成，第五百个字前后合腔几成。

"起先谁都差不多，"葛婆说，"歌唱长了，还接不上，那才叫不会接。"

**一、背熟的老话**

班主罗三挑的第一批接腔孩子，都是在码头听惯了歌的。他们的本事是"熟"：听见"明"，接"月"；听见"撑"，接"船"；听见"一江"，接"春水"。罗三把几十年的旧歌本搬出来，让孩子们背了整整一个冬天，背到看见上一个字，下一个字就自己从嘴里跳出来。

起初几场确实漂亮。歌手唱"青山"，孩子接"绿水"，台下一片叫好。可葛婆的两根竹签却纹丝不动：第五十个字前后合腔四成，第五百个字前后，还是四成。

毛病全出在那些现编的名字上。歌手唱"阿铎撑着青篷船去了渡溪"，唱到"阿"，孩子接"妈"——旧歌本里，"阿"后面最常跟的就是"妈"。那一夜"阿铎"出现了二十几回，孩子们回回接"阿妈"，回回落腔。旧歌本里压根没有阿铎这个人；背得再熟，也背不出今晚才出生的名字。

罗三急了："那就每唱完一首，连夜把这首也背进去！"

葛婆摇头："你要他们今晚就会接今晚的歌。等你连夜背进去，歌会早散了；明晚的歌，又是一群新名字。"

**二、往回翻牌**

第二年，罗三换了法子。他在歌手身后摆一条长案，歌手每唱一个字，就有人把这个字写在一张竹牌上，牌角注上编号，按顺序排上案。罗三挑了个识字的女孩阿棹坐在案边：既然旧歌本里没有今晚的名字，那就让她看今晚已经唱过的牌。

只是长歌会有条老讲究，罗三也改不了：接腔的人每唱一个字之前，只能"看一眼"——拿心里的念头去和案上所有的牌一齐比，哪几张最对得上，就盯着那几张，把牌上的字唱出来。看一眼，唱一个字，不许看第二眼，更不许先找到一张、再顺手去摸它旁边那张。

阿棹很快发现了这一眼的难处。歌手唱到第二回"阿"，她心里念着"阿"，去案上找——最对得上的，自然是前面那张写着"阿"的牌。她盯着它，唱出来的也就只能是"阿"。

"阿——阿？"歌手转身瞪她。

她真正想要的，是前面那张"阿"右手边的那张"铎"。可"铎"那张牌上只写着"铎"，和她心里念着的"阿"毫不相干；牌角的编号倒是写着，可她还不知道前面那张"阿"排在第几，又怎么知道该找哪个编号？要知道，就得先看一眼；可一眼已经用掉了。

葛婆的竹签只挪了一点点：歌手有时确实会把前面唱过的字再唱一遍，阿棹盯着旧牌，偶尔碰巧对上。四成，到四成半。

有人出主意，说阿棹年纪小，案上的牌太多看花了眼，换个眼力好、记性好的大孩子就行。换了，竹签还是四成半。问题不在眼力，也不在记性——一眼之内，就是做不到"找到它，再往右挪一张"。

**三、牌边的一笔**

第三年，葛婆亲自来管。她没有换掉阿棹，而是在长案前头，牌刚放上案的地方，又添了一个女孩，叫阿篙。

阿篙的活计听起来笨得可笑：每当一张新牌放上案，她也只看一眼——不过她找的不是字，是编号，专找编号比这张小一的那张牌。找到了，她读出那张牌上的字，拿细笔在新牌的边上添一行小字："前一张是某"。

"铎"那张牌放上来，阿篙看一眼编号小一的牌，是"阿"，便在"铎"的牌边写下"前一张是阿"。"撑"放上来，牌边写"前一张是铎"。她从不涂改牌上原来的字，只往边上添——牌还是那张牌，只是多了一笔。

阿棹的位置往后挪，坐在阿篙后面，等阿篙写完了才轮到她。她那一眼的找法也换了：歌手唱到"阿"，她不再去找写着"阿"的牌，而是去找牌边写着"前一张是阿"的牌。

一眼扫过去，对得上的只有一张——写着"铎"。

她张口就是"铎"。合腔。

那一夜，"阿铎"第一次出现时，两个女孩照样落腔——今晚的歌里还没有这个名字，谁也无从知道。可从第二次起，只要歌手唱出"阿"，阿棹就接"铎"；唱出"青篷"，她就接"船"。后半夜，葛婆第五百个字的那根竹签，一下子越过了七成；第五十个字的那根，几乎没动。

罗三不服，说这是碰巧今晚的歌好接。葛婆便叫歌手专唱一串谁也没听过的怪音——"咯伊啵哚咪嗒……"——唱完一遍，再原样唱一遍。第一遍，两个女孩几乎全落；第二遍，几乎全合。罗三愣了半天：这串音不在任何歌本里，也不可能在任何人的记忆里。

后来他又试过把两个女孩的座次对调，让阿棹坐在前头、阿篙坐在后头。立刻全乱了：阿棹去找"前一张是阿"的时候，那行小字还没人写。也试过让阿篙一人兼两样活，可她每个字只有一眼，写批注用掉了，就没法再去找。

这套配合其实不是一夜练成的。葛婆的记分簿上，起初一个多月，两个女孩合练的竹签一直不见起色，某几天还略往下掉了一点；然后在短短几天里，第五百个字的那根陡然窜了上去，此后便稳住了。罗三一直以为她们是慢慢熬出来的，翻开簿子才看出，那是一道坎，不是一道坡。

再往后，罗三再没给她们背过一首新歌，也没在哪一夜改过她们的规矩。歌一首比一首怪，名字一夜比一夜生，她们却总是越唱到后半夜，接得越准。

散会那晚，罗三问葛婆，到底教会了她们什么。

葛婆收起竹签："她们一首歌也没学会。她们学会的，是在今晚的歌里学——上一回这个字后面跟的是什么，这一回，多半还跟什么。"

### 2. 核心机制

归纳头实现 […A][B]…[A]→[B]；由较早层的前一 token 头（借位置信息注意 i-1，把前一 token 写入残差流）与较后层的归纳头（查询匹配“前一 token 为 A”的键，OV 把 B 写回、提升 B 的 logit）经 K-组合构成，故至少两层（Elhage et al., 2021[1]）；单层纯注意力≈二元统计+跳跃三元组。与内容无关、不改权重，是上下文学习的一种具体机制。上下文学习分数=第500 token 损失−第50 token 损失（Olsson et al., 2022[2]）。训练早期出现相变：归纳头形成、ICL 分数陡降、损失曲线出现小鼓包，单层模型无此现象；小型纯注意力模型有较直接的因果（消融）证据，大模型主要为相关性证据。

### 3. 隐喻对照

- 歌手唱出的字 ↔ 输入序列中的 token
- 接腔孩子抢先唱下一个字 ↔ 下一个 token 预测
- 旧歌本、背了一冬天 ↔ 训练中存入权重的统计规律（如二元统计"A 后常跟什么"）
- "阿"后面接"阿妈" ↔ 只靠训练语料统计，对上下文中新出现的组合无能为力
- 连夜把今晚的歌背进去 ↔ 用更新权重（微调）来适应新内容——合理但错误的方向；归纳头不改权重
- 葛婆比第 50 字与第 500 字的合腔 ↔ Olsson et al. 的上下文学习分数（第 500 与第 50 个 token 的损失差）
- 长案上按序排开的竹牌 ↔ 各位置的残差流
- 牌角编号 ↔ 位置信息
- "只能看一眼"、和所有牌一齐比、盯着最对得上的那几张 ↔ 一个注意力头：查询与所有键比较得到注意力分布，一次只做一次加权读取
- 把盯着的牌上的字唱出来 ↔ OV 电路把被注意位置的 token 信息写出、提升其 logit
- 阿棹独自找"阿"只能唱出"阿" ↔ 单层纯注意力：能匹配到先前相同 token，却无法取到它之后那个 token
- 竹签只挪到四成半 ↔ 单层模型只有有限的利用上下文能力（示意）
- 换眼力好、记性好的孩子无用 ↔ 瓶颈不在单个头的容量，而在单次注意力无法完成"匹配后错位"
- 阿篙按编号找前一张牌 ↔ 前一 token 头：借位置信息注意到 i-1
- 在牌边添"前一张是某"、不涂改原字 ↔ 把前一 token 信息加写进残差流（呼应第7天"只取水、只倒水"）
- 阿棹改找"牌边写着前一张是阿"的牌 ↔ 归纳头的键由前一层写入的信息构成（K-组合）
- 找到"铎"并唱出"铎" ↔ 注意到 B 的位置并输出 B
- "阿铎"首次出现必落腔 ↔ 模式首次出现时，上下文中尚无可借鉴的先例
- 怪音唱两遍，第二遍几乎全合 ↔ 重复随机 token 序列实验：第二遍的损失大幅下降
- 座次对调就全乱 ↔ 组合必须"前层写、后层读"，顺序不可颠倒
- 阿篙不能一人兼两样活 ↔ 单个头单次注意力无法同时完成两步
- 起初一个多月不见起色、略往下掉，然后几天内陡然窜升 ↔ 训练中的相变及损失曲线上的鼓包
- 再没背新歌、没改规矩，却越到后半夜越准 ↔ 推理时权重固定，能力来自上下文
- "她们学会的，是在今晚的歌里学" ↔ 训练得到的是一种通用的上下文学习电路，而非具体内容

### 4. 深度锚点

1. **两层组合与 K-组合**：归纳头依赖前一层头写入残差流的"前一 token"信息来构造自己的键；单个头的一次注意力只能按"内容与位置的匹配"选位置，不能"找到 A 后再右移一格"。这是"至少两层"这一结论的来源（Elhage et al., 2021[1]）。
2. **相变（phase change）**：Olsson et al. (2022) 观察到，两层及以上的模型在训练早期会出现一次相对突然的转变：归纳头形成，上下文学习分数陡然改善，训练损失曲线上同时出现一个小"鼓包"；单层模型没有这一现象。他们据此论证归纳头可能是上下文学习的重要乃至主要机制，但证据强度分层次：对小型纯注意力模型有较直接的因果证据（如消融），对大模型则主要是相关性证据。

## 分歧与限度

- 常见误区：**"归纳头 = 全部的上下文学习"**：不对。Olsson et al. (2022) 对小模型的证据较强，对大模型主要是相关性证据；大模型中还存在更抽象的、不要求 token 完全相同的类似头，上下文学习也可能涉及其他机制。
- 常见误区：**"上下文学习是在推理时偷偷更新了权重"**：不对。推理时参数固定；归纳头的"学习"体现为前向计算中对上下文信息的读取与组合。
